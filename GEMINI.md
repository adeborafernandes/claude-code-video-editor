# GEMINI.md — claude-code-video-editor

Antes de fazer qualquer coisa neste repositório, leia `AGENTS.md` na raiz — é onde está a
sequência operacional completa (customização de identidade na primeira execução, corte
editorial, camada visual, legendas, montagem final) e as instruções que valem pra qualquer
agente de código, não só pra este arquivo. Leia também `README.md` pra contexto geral do
projeto.

Este arquivo existe porque o Gemini CLI lê `GEMINI.md` por padrão, não `AGENTS.md` — é só um
apontador; o conteúdo de verdade não é duplicado aqui pra não haver risco de desalinhar os dois
com o tempo.
